# RadarNet: Deep Learning-Based Radar Object Detection [with MATLAB Code, not a paper]

1. **Improved Detection Accuracy**: By leveraging the advantages of radar technology and deep learning algorithms, RadarNet can achieve higher detection accuracy than traditional methods.
2. **Real-world Reliability**: Our neural network is designed specifically for performing excellently in real-world conditions. In reality, factors such as weather, lighting, and object complexity can significantly impact detection performance.
3. **Edited Dataset**: We are generating carefully curated datasets for training, testing, and validation. These datasets ensure that our neural network is trained on diverse and representative examples, achieving robust and generalized detection capabilities.
4. **Efficient Information Extraction**: RadarNet focuses on designing a neural network architecture that can effectively extract meaningful information from raw radar data. This ensures that our system can accurately detect and classify interested objects.
Contribution - Advancing Object Detection Based on Radar**: By combining radar technology with state-of-the-art deep learning techniques, RadarNet advances the field of object detection methods, particularly in the realm of radar sensing.
- Ensuring Autonomous Systems are Safer***: Our ultimate goal is to provide autonomous systems with safer, more intelligent object detection capabilities. RadarNet plays a crucial role in enhancing the perception abilities of autonomous vehicles and other unmanned systems, thereby improving safety and reliability.
Model Training Process 1. Navigate to the radar dataset generator and execute `clutter_dataset.m` to generate the dataset.
2. Divide the dataset images (Clutter and noClutter) into training sets, validation sets, and test sets or use the pre-generated "radar dataset".
3. Run `Radar_dnn.mlx` to train the model.
We provide a pre-trained model for immediate use.
To use the pre-trained model
1. Adjust the image size to (374,500,3)
2. Run "RunPreTrainedModel(images_path)" program
3. Check the results.
